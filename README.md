## ✨ Key Features & Technical Highlights

* **Pure Frontend Logic:** 100% implementation using Vanilla JavaScript (no frameworks) to handle game loops, physics, and state management.
* **Complex Algorithm Showcase:** Includes advanced logic implementation for challenges like the **Sudoku Solver** and complex physics (e.g., **Flappy Bird** clone).
* **DOM & Animation Mastery:** Demonstrates efficient **DOM manipulation** and custom animation techniques for smooth, responsive gameplay across all devices.
* **Diverse Game Genres:** Features a broad spectrum of games—from classic arcade (**Snake, Tetris**) to logic puzzles (**2048, Sudoku**).
